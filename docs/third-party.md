# 第三方依赖

本组件附带 Three.js r186 的 ES Module 文件，以便无需 CDN 或运行时下载即可使用。

- 官方项目：<https://github.com/mrdoob/three.js>
- 本地文件：`components/astral-library/vendor/three.module.js`、`three.core.js`
- 许可：MIT，完整原文位于 `components/astral-library/vendor/THREE-LICENSE.txt`。

复制或分发组件时，请一并保留 Three.js 的许可文件。建筑生成、细部装饰、程序材质、控件与示例源码随本仓库提供；本次没有添加外部图片、3D 模型或商业素材。
